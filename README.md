<summary><h3>🩹 CRAG — Corrective Retrieval-Augmented Generation</h3></summary>

- Corrective RAG system built with **LangGraph + FAISS**
- LLM-based document evaluator scores retrieved chunks against upper/lower confidence thresholds → **CORRECT / AMBIGUOUS / INCORRECT** verdict
- Context decomposed into sentence-level "strips," filtered by a strict LLM relevance filter, then refined
- **Tavily web-search fallback** triggers automatically when local retrieval is insufficient or ambiguous

`LangGraph` `FAISS` `HuggingFace Embeddings` `Corrective RAG` `Tavily Web Search` `Pydantic Structured Output`

</details>
